# Data Structures Lab Programs

This repository contains C implementations of various Data Structures lab experiments (Ex 1 to Ex 12).

## Programs included

| File | Description |
|------|-------------|
| Ex_1A_Array_Implementation_of_List_ADT.c | Array Implementation of List ADT |
| Ex_1B_Implementation_of_Singly_Linked_List.c | Singly Linked List |
| Ex_2_Implementation_of_Circular_Linked_List.c | Circular Linked List |
| Ex_3A_Array_Implementation_of_Stack.c | Array Implementation of Stack |
| Ex_3B_Array_implementation_of_Queue.c | Array Implementation of Queue |
| Ex_4A_Linked_List_Implementation_of_Stack.c | Linked List Implementation of Stack |
| Ex_4B_Linked_List_Implementation_of_Queue.c | Linked List Implementation of Queue |
| Ex_5_Implementation_of_Binary_Search_Tree.c | Binary Search Tree |
| Ex_6_Implementation_of_AVL_Tree.c | AVL Tree |
| Ex_7A_Breadth_First_Search.c | Breadth First Search |
| Ex_7B_Depth_First_Search.c | Depth First Search |
| Ex_8_Applications_of_Graph.c | Applications of Graph (Dijkstra) |
| Ex_9_Implementation_of_Priority_Queue.c | Priority Queue (Heap) |
| Ex_10_A_Linear_Search.c | Linear Search |
| Ex_10_B_Binary_Search.c | Binary Search |
| Ex_10_C_Insertion_Sort.c | Insertion Sort |
| Ex_10_D_Quick_Sort.c | Quick Sort |
| Ex_11_A_Hashing_with_seperate_chaining.c | Hashing with Separate Chaining |
| Ex_11_B_Hashing_with_open_addressing.c | Hashing with Open Addressing |
| Ex_12_Student_Record_System.c | Student Record System |

## How to compile and run

```bash
gcc filename.c -o filename
./filename
```

All programs are interactive menu-driven implementations based on the lab exercises.
